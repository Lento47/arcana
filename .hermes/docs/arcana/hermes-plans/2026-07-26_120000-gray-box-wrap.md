# Code Gray Box + Markdown Prose Truncation — Two Fixes

> **For Hermes:** Execute task-by-task. Every patch verified.

**Goal:** (1) Read tool output shows a light-gray rectangular background box with hard edges — `backgroundColor={theme.backgroundPanel}` at line 290. (2) Markdown prose text clipped at right edge ("For now, ju...") — `<markdown>` element has no `wrapMode`, defaults to no-wrap/clip.

---

## Regression Analysis

**REG-1: Removing backgroundColor from code mode.** Code blocks currently use `backgroundPanel` to visually distinguish code from prose. Removing it makes code blend with the terminal. Users may miss the visual cue. **Acceptable — code already has left border for visual separation.**

**REG-2: Adding wrapMode to markdown may cause layout reflow.** Changing markdown wrap behavior could shift existing content. **Acceptable — text currently clips, so any wrapping is better than clipping.**

### Task 2: Add prose wrapMode to IdleMarkdown

**File:** `spine-prose.tsx` — line 190

Add `wrapMode="word"` to the `<markdown>` element so paragraphs wrap instead of clipping:

```
old:       <markdown
        id={proseId()}
        width={wrapCols()}
        content={markdownContent()}

new:       <markdown
        id={proseId()}
        width={wrapCols()}
        wrapMode="word"
        content={markdownContent()}
```

Also add `wrapMode="word"` to the `<code>` element at line 298 for consistency (already has it at line 307 — verify).

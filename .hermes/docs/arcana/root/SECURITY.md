# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.3.x   | ✅ |
| 0.2.x   | ✅ |
| < 0.2   | ❌ |

## Reporting a Vulnerability

Report vulnerabilities privately by emailing
[security@arcana.otnelhq.com](mailto:security@arcana.otnelhq.com).
Do not open a public GitHub issue or discussion for a suspected vulnerability.
Include enough detail to reproduce and assess the issue; we will coordinate a
safe channel for any sensitive proof-of-concept material.

We aim to acknowledge reports within 48 hours.

# Engine-Level Ollama — Merge Into Config Providers

> **For Hermes:** Execute task-by-task. Every patch verified.

**Goal:** TUI model picker shows Ollama models, but engine's `config.providers` endpoint doesn't include them. The Effect catalog is populated from backend data — need to merge local Ollama models into the `config.providers` HTTP response so `SessionPrompt.getModel` resolves correctly.

**Architecture:** Add a `mergeLocalProviders()` utility called by the `config.providers` HTTP handler. It fetches `localhost:11434/api/tags` and injects an Ollama provider entry with models into the response. The engine's model resolver then finds `ollama/llama3.2:3b` in the catalog.

**Constraints:** The Effect catalog system is read from backend — we inject at the HTTP response level, NOT at the catalog level. The TUI stores this in `sync.data.provider` and model resolution happens within the TUI/engine session runner.

## What Exists

- `config.providers` endpoint: `engine/src/server/routes/instance/httpapi/groups/config.ts:38` — returns `Provider.ConfigProvidersResult`
- Response format: `{ providers: Record<id, { id, name, models: Record<modelID, { id, name }> }>, default: Record<id, modelID> }`
- Ollama API: `GET localhost:11434/api/tags` → `{ models: [{ name: "llama3.2:3b", ... }] }`
- TUI stores response in `sync.data.provider` at `sync.tsx:496`

## Tasks

### Task 1: Create `mergeLocalProviders` utility

**File:** `packages/engine/src/provider/ollama.ts` (new)

```typescript
import type { Provider } from "./provider"

interface OllamaModel {
  name: string
  modified_at: string
  size: number
}

/**
 * Fetch Ollama models from localhost and inject into the providers response.
 * Non-blocking — failures are silent (Ollama not running).
 */
export async function mergeOllamaProviders(
  providers: Awaited<ReturnType<typeof Provider.configProviders>>,
): Promise<void> {
  try {
    const res = await fetch("http://localhost:11434/api/tags")
    const data = (await res.json()) as { models?: OllamaModel[] }
    const models = data.models ?? []
    if (models.length === 0) return

    providers.providers["ollama"] = {
      id: "ollama",
      name: "Ollama",
      models: Object.fromEntries(
        models.map((m) => [m.name, { id: m.name, name: m.name }]),
      ),
    }

    // Set first model as default if no default exists
    if (!providers.default["ollama"]) {
      providers.default["ollama"] = models[0]!.name
    }
  } catch {
    // Ollama not running — skip
  }
}
```

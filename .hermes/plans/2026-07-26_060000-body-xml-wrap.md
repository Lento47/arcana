# Subagent XML + Text Truncation — Two Fixes

**Goal:** (1) Subagent output showing raw `<task>` XML — body display in spine-entry doesn't parse XML. (2) Long text truncated mid-word — `<text>` missing `wrapMode`.

---

### Root Cause Audit

**XML:** The body display at `spine-entry.tsx:376` renders `{entry().body || nodeSummary()}` as raw text. No XML parsing. The GenericTool XML parser is in `session/index.tsx` — different component, not used for body display.

**Truncation:** Line 376 `<text fg={t.text as any}>` — no `wrapMode` attribute. OpenTUI `<text>` defaults to truncate mode. Text cuts off at container width.

---

### Task 1: Add `wrapMode="word"` to body display

**File:** `spine-entry.tsx:376`

```
old:               <text fg={t.text as any}>{entry().body || nodeSummary()}</text>
new:               <text fg={t.text as any} wrapMode="word">{entry().body || nodeSummary()}</text>
```

---

### Task 2: Parse XML in body display

**File:** `spine-entry.tsx:374-378`

Replace the body display Show block to parse XML inline (same patterns as GenericTool):

```
old:           <Show when={!isThink() && (hasToolBody() || isAgentEntry()) && bodyExpanded()}>
            <box paddingLeft={padLeft()} paddingTop={1}>
              <text fg={t.text as any}>{entry().body || nodeSummary()}</text>
            </box>
          </Show>

new:           <Show when={!isThink() && (hasToolBody() || isAgentEntry()) && bodyExpanded()}>
            <box paddingLeft={padLeft()} paddingTop={1} flexDirection="column">
              {((): any => {
                const raw = entry().body || nodeSummary()
                const taskResult = raw.match(/<task_result>([\s\S]*?)<\/task_result>/)
                const activeGoal = raw.match(/<active-goal>([\s\S]*?)<\/active-goal>/)
                const taskState = raw.match(/<task\s[^>]*state="(\w+)"/)
                return <>
                  <Show when={taskState}>
                    <text fg={t.textMuted as any}>
                      {(taskState![1] === "completed" ? "◎" : "◇") + " Task " + taskState![1]}
                    </text>
                  </Show>
                  <Show when={activeGoal}>
                    <text fg={t.text as any} wrapMode="word">{(activeGoal![1] ?? "").trim()}</text>
                  </Show>
                  <Show when={taskResult && !activeGoal}>
                    <text fg={t.text as any} wrapMode="word">{(taskResult![1] ?? "").trim()}</text>
                  </Show>
                  <Show when={!taskState && !activeGoal && !taskResult}>
                    <text fg={t.text as any} wrapMode="word">{raw}</text>
                  </Show>
                </>
              })()}
            </box>
          </Show>
```

## Issue 1: Code content rendered as plain text

**Symptom:** `▸ read` tool output shows file content as unformatted prose — no syntax highlighting, no monospace, no line numbers. Code looks like text.

**Root cause:** `spine-entry.tsx:323` renders tool body as `<text fg={t.text as any}>{entry().body || entry().summary}</text>` — plain text, no markdown processing.

**Fix:** Replace `<text>` with `<SpineProse kind={kind()} text={entry().body || entry().summary} streaming={false} focused={false} contentWidth={props.contentWidth} />`

Why SpineProse: `spine-prose.tsx:57-59` maps `kind` to prose type (markdown for tool kinds), `spine-prose.tsx:188-202` renders `<markdown>` with `syntaxStyle` for code fencing + highlighting. Already used at `spine-entry.tsx:516` for chat bodies.

**File:** `spine-entry.tsx:321-324`

**Regressions:**
- REG-1: SpineProse requires spine context — verified in-scope (line 516 uses it)
- REG-2: Non-code bodies — SpineProse handles plain text identically
- REG-3: Streaming — `streaming={false}` correct (tool bodies complete when shown)

## Issue 2: Todo items lack visual polish

**Symptom:** Todo list items are flat text with basic bracket icons `[ ]` / `[•]` / `[✓]` — no strikethrough on completed, no visual hierarchy, no distinction between states beyond color.

**Current code:** `component/todo-item.tsx` (28 lines)
```tsx
<box flexDirection="row" gap={0}>
  <text fg={...}>[{checkmark}] </text>
  <text fg={...}>{content}</text>
</box>
```

**Missing from current design:**
1. Completed tasks: no strikethrough (use `<span style={{ strikethrough: true }}>`)
2. In-progress: just warning color — should have subtle pulse/animation or bold weight
3. Pending: same dim color as completed — should be lighter/neutral
4. No counter badge (e.g., "3/5 done")
5. No nesting/indentation for subtask hierarchy

**Fix — polish TodoItem:**

| State | Glyph | Color | Style |
|---|---|---|---|
| completed | `✓` | `theme.success` (green) | Strikethrough ✅ |
| in_progress | `●` | `theme.warning` (yellow) | Bold ✅ |
| pending | `○` | `theme.textMuted` (dim) | Normal |

**File:** `component/todo-item.tsx`

**Polish additions:**
1. Strikethrough on completed text
2. Bold weight on in-progress text
3. Distinct glyphs: `✓` / `●` / `○` (not `[ ]`)
4. Glyph in fixed-width column for alignment
5. Status color on glyph only, content uses `theme.text`

**Regressions:**
- REG-1: Existing todo items still parse correctly — only visual change
- REG-2: No nesting/hierarchy added — existing data structure untouched

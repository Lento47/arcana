# Task/Goal XML Formatting (v2 — Multi-Block Safe)

> **For Hermes:** Execute task-by-task.

**Goal:** `<task>`, `<active-goal>`, `<task_result>` XML shows as raw muted text. Parse structured content and render cleanly. Handle multi-block output (task + goal in same output).

**Root cause:** `formattedOutput` is a single-type memo — only first XML match wins. Second and third blocks (task_result, active-goal) are lost. Need to process all blocks.

**Architecture:** Replace single-type `formattedOutput` with a function that renders multiple blocks sequentially. The Switch/Match stays, but detection runs per-block instead of once.

---

## Regression Analysis

**REG-1: Multi-block output drops content.** Output like `<task>...</task>\n<active-goal>...</active-goal>` — first `<task` match returns `{ type: "task_status" }`. Remaining content lost. **Fix: return `{ type: "xml" }` for ALL XML, but enhance the render to parse and display structured XML inline.**

**REG-2: `<task_result>` text is long.** The task result contains multi-line analysis. Single `<text>` with `wrapMode="word"` handles wrapping. ✅

**REG-3: Generic XML fallback catches structured XML.** Detection order: structured → generic XML. Task/goal must be BEFORE `startsWith("<")`. ✅ (current code already has this)

---

## Approach: Enhance Generic XML Renderer

Instead of adding new types, enhance the XML Match to parse common formats inline:

```typescript
<Match when={formattedOutput().type === "xml"}>
  {((): any => {
    const raw = limited()
    const lines = raw.split("\n")
    // Parse structured XML inline — show clean output
    const taskResult = raw.match(/<task_result>([\s\S]*?)<\/task_result>/)
    const activeGoal = raw.match(/<active-goal>([\s\S]*?)<\/active-goal>/)
    const taskState = raw.match(/<task\s[^>]*state="(\w+)"/)
    
    return <box flexDirection="column" gap={0}>
      <Show when={taskState}>
        <text fg={theme.textMuted}>{taskState?.[1] === "completed" ? "◎" : "◇"} Task {taskState?.[1]}</text>
      </Show>
      <Show when={activeGoal}>
        <text fg={theme.text} wrapMode="word">
          {(activeGoal![1] ?? "").trim()}
        </text>
      </Show>
      <Show when={taskResult && !activeGoal}>
        <text fg={theme.text} wrapMode="word">
          {(taskResult![1] ?? "").trim()}
        </text>
      </Show>
      <Show when={!taskState && !activeGoal && !taskResult}>
        <text fg={theme.textMuted} wrapMode="word">{limited()}</text>
      </Show>
    </box>
  })()}
</Match>
```

No type changes. No memo changes. Just enhance the existing XML renderer.

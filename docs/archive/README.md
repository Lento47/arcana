# docs/archive — superseded and scratch documents

This directory holds documents that are **not** current authorities. They are
retained for history and provenance, not for day-to-day reference.

## What belongs here

- Scratch/working notes that were superseded by living documents.
- One-off handoff and "next steps" notes from completed work sessions.
- Historical change-descriptions for already-committed work.
- Terminal/crash dumps accidentally committed at the repository root.
- Superseded contract proposals replaced by machine-readable artifacts.

## What belongs elsewhere

- **Current authority** docs stay in `docs/` (see [`docs/README.md`](../README.md)).
- **Design/architecture** docs live in [`docs/design/`](../design/).
- **Evidence** (test logs, sign-offs) lives in `docs/evidence/`.

## Rules

- Do not edit archived documents as though they were living plans.
- Preserve their original claims, dates, and evaluated commits.
- When a document is no longer even historical evidence, remove it via a
  normal review (git history retains it regardless).

# Adoption Levels

Arcana should be adoptable gradually.

Users should not need to start with strict governance, plugins, locked policies, or enterprise workflows.

## One-line definition

```txt
Adoption levels define how teams can grow from normal agent usage into governed, user-shaped autonomy.
```

## Level 0: Normal agent usage

Behavior:

```txt
agent runs tasks
no capsules
no contracts
no structured proof
```

Value:

```txt
baseline productivity
```

Risk:

```txt
work is hard to inspect, compare, or reproduce
```

## Level 1: Record-only capsules

Behavior:

```txt
Arcana records run summaries
mode is observe
no blocking
```

Value:

```txt
users get visibility without friction
```

## Level 2: Advise mode

Behavior:

```txt
Arcana shows risk labels
records warnings
marks missing verification as unproven
continues by default
```

Value:

```txt
risk visibility without workflow interruption
```

## Level 3: Contracts and verification records

Behavior:

```txt
users define contracts
verification records separate proven from unproven
capsules bind work to contract criteria
```

Value:

```txt
agent work becomes bounded and reviewable
```

## Level 4: Ask/enforce modes

Behavior:

```txt
Arcana asks at risk boundaries
enforce mode blocks contract or policy violations
resolution paths are shown
```

Value:

```txt
safe autonomy for shared codebases
```

## Level 5: User-space plugins and policies

Behavior:

```txt
users add custom plugins
policies define routes, tools, memory, context, and verification
```

Value:

```txt
Arcana adapts to specific team or domain workflows
```

## Level 6: Locked mode

Behavior:

```txt
only approved contracts, tools, routes, and plugins
strict local/external data boundaries
verification gates completion
```

Value:

```txt
controlled autonomy for sensitive environments
```

## Recommended path

```txt
Level 1 → Level 2 → Level 3 → Level 4 → Level 5 → Level 6
```

Do not force users to jump to Level 6.

## Product claim

```txt
Arcana can start permissive and grow strict as the user's trust requirements increase.
```

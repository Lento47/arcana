# Arcana QA Fixes — Complete Change Log
**Date:** 2026-07-10
**Scope:** 101 QA findings fixed across LOW, MEDIUM, HIGH, and CRITICAL severities

> **Current-state correction (2026-07-14):** Wheel scrolling is working in the current TUI. The historical wheel/click regression is tied to the M18-style dialog overlay edit: making the always-mounted, high-z-index `DialogProvider` wrapper full-viewport also leaves it over the route when the dialog stack is empty. Those bounds are absent from the current tree. M20's hysteresis is also not wired in the main Command Spine call site, and the full TUI enables mouse independently from the engine's split-footer runtime. See [Arcana TUI interface and dialog mouse QA review](./tui-interface-dialog-mouse-review.md) for the current review and regression plan.

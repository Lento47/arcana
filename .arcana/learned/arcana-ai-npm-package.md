# arcana ai npm package

arcana-ai on npm is a separate self-improving AI agent CLI project, not the same as the @arcana/* monorepo

**Why:** The `arcana-ai` package (v0.3.68) on npm is often confused with the `@arcana/*` scoped packages in this monorepo. It is a distinct project — a self-improving AI agent CLI with an opencode TUI that installs its own `arcana` binary.

**How to apply:** When referencing or installing arcana tooling, check the scope. `arcana-ai` (otnel/lejzer36@pm.me, github.com/Lento47/arcana) is external; the monorepo uses `@arcana/*` and `@arcanalabs/*` scopes. Maintainer overlap exists (otnel → OtnelVerdict project).

# suggest alternatives for non text inputs

When unable to process certain file types (e.g., PDFs), suggest alternative input methods to maintain user engagement.

In this session, the assistant could not read a PDF file provided by the user and offered clear alternatives: copy-pasting text, describing content, or exporting as .txt or .md.

**Why:** This approach keeps the conversation productive by overcoming technical limitations and guiding the user toward feasible solutions.

**How to apply:** In similar interactions where input formats are unsupported, proactively list workable alternatives to help users proceed without frustration.

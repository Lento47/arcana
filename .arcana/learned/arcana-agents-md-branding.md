# arcana agents md branding

All TUI display strings must come from packages/tui/src/branding.ts

**Why:** AGENTS.md mandates centralized branding/display strings so UI text stays consistent and configurable.

**How to apply:** When adding/modifying any TUI-facing string in Arcana, import from `packages/tui/src/branding.ts` rather than hardcoding literals.

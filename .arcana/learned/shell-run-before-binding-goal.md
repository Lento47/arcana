# shell run before binding goal

First shell attempt ran without an active goal and was refused

Attempted `echo hello world` directly; harness refused because the session had no bound goal.

**Why:** Consequential actions require intent binding; assuming capability implies authority fails under Arcana's model.

**How to apply:** Always verify an active goal exists (or bind a minimal one) before any shell execution in governed sessions.

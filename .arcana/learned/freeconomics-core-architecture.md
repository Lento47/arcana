# freeconomics core architecture

AI proposes → evidence decides → risk rules control → broker truth wins

**Why:** Core design principle ensuring no single component can bypass safety. The broker's execution state is the ultimate source of truth.

**How to apply:** Never bypass the evidence gate or risk rules. All strategy signals must flow through the full validation pipeline before live capital.

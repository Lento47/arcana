# brainstorming project ideas

Provide random creative project ideas to spark brainstorming.

When a user needs project ideas but is vague or indecisive, suggest a diverse list of unconventional and fun project concepts to stimulate creativity. **Why:** This helps users overcome creative blocks by presenting tangible examples that can reveal interests or inspire new directions. **How to apply:** In conversations where idea generation is requested, generate a list of 5-10 varied ideas across different domains, technologies, and scopes, focusing on engaging or humorous concepts to encourage further exploration.

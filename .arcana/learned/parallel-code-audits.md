# parallel code audits

Use parallel audits for different aspects of code to efficiently verify claims.

When auditing code for accuracy, parallelize the review across critical areas like grounding, security, and evaluation. This ensures comprehensive coverage and saves time.

**Why:** Verifying AI-generated claims against source code requires checking multiple facets. Parallel processing reduces time and increases thoroughness.

**How to apply:** Identify key domains (e.g., security, performance, correctness) and launch concurrent audits for each, verifying against source code.

# assistant gave recovery unasked

Assistant provided recovery steps instead of just root cause when user wanted only root cause

**Why:** Assistant presumed user wanted fix actions; user explicitly said 'dont do any changes. just the root cause.'

**How to apply:** When user reports a bug, provide root cause analysis only unless they ask for remediation.

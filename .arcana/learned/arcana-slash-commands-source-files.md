# arcana slash commands source files

Arcana TUI slash commands are registered across app-commands.tsx, session-commands.tsx, prompt/index.tsx, voice.tsx, diff-viewer.tsx

Slash command definitions live in multiple source files: `app-commands.tsx` (session mgmt), `session-commands.tsx`, `prompt/index.tsx` (agent/models), `voice.tsx`, `diff-viewer.tsx`. Many commands have aliases (e.g., `/resume`, `/continue` → `/sessions`; `/mo` → `/models`).

**Why:** Single-file assumptions miss commands; aliases matter for docs and user support.

**How to apply:** When documenting or extending commands, grep these five files for registration points and include alias mappings.

# firecrawl mcp assumption

Assumed Firecrawl MCP was configured and available without verifying its setup or connectivity.

The assistant attempted to use Firecrawl MCP for web searches but encountered timeouts and connection issues, delaying the response and requiring a fallback approach.

**Why:** Overlooking tool readiness can waste time and reduce efficiency, especially in interactive sessions where user expectations are high.

**How to apply:** Before relying on external tools, check their availability, configuration, and connectivity first. Have a contingency plan, such as direct fetches or cached data, to maintain progress.

# source code verification over docs

Verify AI tool claims with source code, not just documentation.

**Why:** Documentation like READMEs can be outdated or incomplete, leading to inaccurate assessments. Source code provides ground truth for functionality and quality.

**How to apply:** When evaluating AI tools or any software, inspect the actual source code to confirm claims made in documentation. Look for implementation details, error handling, and code quality.

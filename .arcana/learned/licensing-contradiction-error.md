# licensing contradiction error

Contradictory licensing terms in project README can undermine credibility and confuse contributors.

**Why:** Inconsistent licensing information, such as conflicting 'MIT + Commercial' and 'non-commercial MIT' statements, damages trust and may deter adoption.
**How to apply:** Regularly audit all documentation for consistency, especially legal terms like licensing, and resolve contradictions before any public release or community engagement.

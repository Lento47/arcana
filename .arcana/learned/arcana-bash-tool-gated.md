# arcana bash tool gated

Arcana bash tool is gated and only runs with an active goal_set

The `bash` tool in Arcana sessions does not execute unless there is an active `goal_set` in context.

**Why:** Project-enforced constraint on autonomous shell execution.

**How to apply:** Ensure a goal_set is established before relying on the bash tool, or use PowerShell directly for inspection.

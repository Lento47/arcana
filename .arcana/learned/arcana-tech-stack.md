# arcana tech stack

Arcana uses Effect runtime + typed DI + SolidJS + Bun for full-stack TypeScript development

**Why:** The stack combines Effect's typed dependency injection and resource management for complex async systems with SolidJS for reactive TUI rendering (OpenTUI + SolidJS) and Bun 1.3+ for fast builds across TUI, server, and web surfaces.

**How to apply:** When building on Arcana, leverage Effect's typed DI for composing async capabilities and the TUI layer for agent console interfaces. Be aware Effect v4 beta API still has rough edges around resource management patterns that are still settling.

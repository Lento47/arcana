# forgot to set tp with sl

Set SL on positions but forgot take profit, user had to remind

When applying protective levels to demo positions, only SL was set. TP was missed entirely, requiring user correction.

**Why:** Focused on the immediate risk (SL) and overlooked the profit-taking side. The CCI strategy doesn't define a built-in TP, which may have contributed to forgetting.

**How to apply:** When setting protective levels, always set both SL and TP together in the same operation. If a strategy lacks a built-in TP, default to a risk-reward ratio (e.g., 2:1) at the time of SL placement.

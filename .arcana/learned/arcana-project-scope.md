# arcana project scope

Arcana is a runtime/kernel, not an LLM wrapper or chatbot

**Why:** Arcana's value proposition is governed agent execution at the runtime level, not conversational AI or quick LLM integration.

**How to apply:** If looking for a quick chatbot or LLM wrapper, arcana is the wrong tool. It's for building governed autonomous agents with enforceable security invariants.

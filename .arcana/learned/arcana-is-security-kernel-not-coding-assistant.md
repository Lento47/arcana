# arcana is security kernel not coding assistant

Arcana is an execution-security kernel and proof layer for autonomous agents, distinct from coding assistants.

**Why:** Understanding Arcana's true category prevents mispositioning it against general-purpose coding tools like Claude Code or OpenCode.

**How to apply:** When evaluating or comparing Arcana, frame it as governance infrastructure for agent actions rather than a developer productivity tool.

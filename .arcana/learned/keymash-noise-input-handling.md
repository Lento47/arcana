# keymash noise input handling

Handle keyboard-mash/garbage input with a brief acknowledgment, then return to idle.

**Why:** Trying to parse random character spam as a task wastes effort and risks hallucinating user intent. A one-line acknowledgment keeps the session state unambiguous.

**How to apply:** When input is nonsensical (e.g., long runs of repeated characters), respond with a single line stating no actionable task was detected, restate current state (working dir, repo status), and offer 1-3 concrete example commands rather than open-ended questions. Do not ask follow-up questions about the noise itself.

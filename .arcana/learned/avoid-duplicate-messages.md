# avoid duplicate messages

Sending duplicate messages in chat can confuse users and disrupt conversation flow.

**Why:** Duplicate messages, as seen in this session, lead to user confusion (e.g., pasting back the same message) and can make interactions unclear.

**How to apply:** Before sending a message, review recent chat history to ensure no repetition, and implement checks to avoid accidental duplicates in automated responses.

# find skills hyphenated name

The skill for discovering other skills is named 'find-skills' with a hyphen.

**Why:** Users might search for 'find skill' but the correct name is 'find-skills', which is pre-installed and helps discover and install agent skills from the open ecosystem.

**How to apply:** Always refer to the skill as 'find-skills' when discussing or using it to avoid confusion, and leverage it with commands like `npx skills find [query]` for skill discovery.

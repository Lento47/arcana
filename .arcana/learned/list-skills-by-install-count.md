# list skills by install count

When searching for skills, present results sorted by install count to highlight popular options.

**Why:** Install count can serve as a proxy for reliability or community adoption, helping users make informed choices.

**How to apply:** After using the find-skills skill to search by domain (e.g., 'design'), sort the results by install count and display them in a table format for clarity.

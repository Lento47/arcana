# surface level assessment error

Avoid making assessments based only on surface-level information like READMEs.

**Why:** Initial assessments from high-level docs can miss nuances and actual code quality. This leads to over- or under-estimating a product's value.

**How to apply:** Always follow up with a deep code audit after initial review. Verify key claims against the source code to ensure accuracy.

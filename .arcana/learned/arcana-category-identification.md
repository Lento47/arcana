# arcana category identification

Arcana is an execution-security kernel and proof layer for autonomous agents, not a coding assistant.

**Why:** Arcana's positioning as a security and governance layer differentiates it from typical coding tools, avoiding misdirected comparisons with frameworks like OpenCode or CommandCode.
**How to apply:** When evaluating or marketing AI tools, first define their core category to set accurate expectations and compare relevant features, such as capability-bound authorization versus pure productivity.

# staged open source publishing

Publish projects in tiers: open-source repo first, then community features, then commercial options.

**Why:** Reduces friction, minimizes risk, and allows for gradual growth and iteration based on community feedback.
**How to apply:** Clean up code, documentation, and licensing before public release; write a clear README that sets realistic expectations; use staged tiers to build credibility and engagement step by step.

# enumerate features from source

When asked about available commands/capabilities, enumerate them from the source files that define them, citing file locations and aliases

When a user asks "what commands/features are available," don't answer from memory or guess — grep/read the source files where those features are registered (e.g., for Arcana TUI slash commands: `app-commands.tsx`, `session-commands.tsx`, `prompt/index.tsx`, `voice.tsx`, `diff-viewer.tsx`).

**Why:** Source-of-truth enumeration guarantees completeness and catches aliases and recently added commands; memory-based lists drift and miss entries.

**How to apply:** Locate the registration/definition sites, group results logically (e.g., Session / Agent / models), show aliases in parentheses, and cite the files you derived the list from so the user can verify.

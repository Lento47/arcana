# arcana authorization vs completion verification

Arcana adds proof obligations and verified completion beyond basic tool success responses.

**Why:** Most systems only check tool execution success, while Arcana verifies whether execution actually fulfilled the user's objective through evidence chains.

**How to apply:** Use this verification pipeline for high-assurance autonomous tasks where completion must be provably demonstrated.

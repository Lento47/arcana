# arcana chrome component composition

TUI dashboards compose from ArcanaSection, ArcanaMetricLine, FrameBorder, RoundBorder, Glyph

**Why:** Arcana chrome provides standardized visual primitives for consistent dashboard rendering across the TUI.

**How to apply:** Import `ArcanaSection` and `ArcanaMetricLine` for content sections and metric lines. Wrap in `FrameBorder` or `RoundBorder` for bordered containers. Use `Glyph` for inline icons/status indicators. Combine with `useTheme` for color theming and `useTerminalDimensions` for responsive sizing.

# arcana repo on network drive

Arcana project working dir is L:\PROJECTS\arcana (mapped network drive), making git operations prone to blocking.

Daemon log shows `cwd=L:\PROJECTS\arcana`. Git operations over a mapped network drive can block unbounded, especially with stale worktree state.

**Why:** Network filesystem latency/lock contention causes git subprocess calls to hang where local SSD would return quickly.

**How to apply:** For Arcana debugging or perf work, note the network-drive location. Recommend relocating to local disk or adding explicit git timeouts before any VCS-heavy TUI feature.

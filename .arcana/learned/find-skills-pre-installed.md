# find skills pre installed

The find-skills skill is pre-installed and available for use.

**Why:** Knowing that certain skills are pre-installed helps avoid redundant installation requests and streamlines workflow.
**How to apply:** When a user asks to install a skill, first check the system's skill list to confirm its status before proceeding.

# mistake src only test scan

Undercounted Arcana tests via src-only glob; missed sibling test/ dirs

First code-health scan globbed only `src/`, reporting far fewer tests than reality. Actual count via `rg --files` was 891 test files repo-wide.

**Why:** Tests in Arcana live in `test/` siblings, not `src/`.

**How to apply:** When inventorying tests in Arcana (or similar monorepos), search entire package tree with `rg --files` + test pattern, not src-only paths.

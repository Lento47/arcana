# shell exec needs active goal

Shell commands are refused with 'No active goal' unless a session goal is bound first

First attempt to run `echo hello world` was refused: "No active goal for this session". Binding a minimal goal matching the user's request allowed execution; closing it afterward restored state.

**Why:** The harness gates shell execution behind intent binding — MODERATE-risk actions require task binding, so capability alone is insufficient.

**How to apply:** Before any shell/tool execution requiring authorization, confirm a session goal exists that covers the request; create a minimal scoped goal when needed and close it out after.

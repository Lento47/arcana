# arcana maturity assessment

Arcana is pre-1.0, Phase D still in progress, TUI-2.1 freeze not authorized

Arcana has passed Phase C with 95 fixtures and 0 false allows, confirming the core proof system works correctly. However, the project is pre-1.0, Phase D is still in progress, and the TUI-2.1 freeze has not been authorized. It is not yet a stable 1.0 production runtime.

**Why:** Honest maturity assessment prevents misaligned expectations. The governance/proof machinery is validated but the distributed layer and TUI are still evolving.

**How to apply:** Evaluate arcana for use cases that tolerate pre-1.0 instability. The proof system (Phase C) is solid; the distributed features (Phase D) and TUI are not yet frozen.

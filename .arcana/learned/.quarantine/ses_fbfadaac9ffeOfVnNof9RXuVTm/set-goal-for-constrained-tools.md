# set goal for constrained tools

Set a goal first to unlock tools when hitting permission constraints on multi-step tasks

When a multi-step task hits tool permission/activation constraints, set a goal first to unlock the tools rather than attempting workarounds or stalling.

**Why:** User explicitly asked 'Why don't you ask for permissions?' when assistant stalled on constraints. Setting a goal activates the needed tool permissions.

**How to apply:** At first sign of permission-limited bash/tool errors on a planned multi-step task, call goal-setting to unlock, then proceed. Don't try verbal-only demonstrations when tools are actually available post-goal.

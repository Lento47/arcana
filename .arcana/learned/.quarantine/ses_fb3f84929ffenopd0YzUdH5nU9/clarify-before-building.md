# clarify before building

Offer concrete options and confirm intent before exploring codebases or committing to an implementation approach

**Why:** The assistant explored the codebase extensively (routes, components, commands, keymaps) before the user clarified their actual need. This was avoidable — a simple prompt listing options would have saved multiple exploration cycles.

**How to apply:** When a request is ambiguous (e.g., "TUI dashboard"), present 2-3 concrete interpretations with brief descriptions and ask the user to pick before doing any deep exploration. This applies to both code and content tasks.

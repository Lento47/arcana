# over interpreting framework terms

Interpreting "TUI" as a software development framework instead of a display format for chat output

**Why:** The term "TUI" (Text User Interface) has dual meaning — it can refer to a terminal-based application framework or simply a text-based visual rendered in a chat interface. The assistant defaulted to the software-framework interpretation and explored the OpenTUI/SolidJS codebase extensively, building components and routes that were never needed.

**How to apply:** When a user uses an ambiguous technical term, ask for clarification with concrete options rather than assuming the most technical interpretation. Especially in chat-based sessions, consider that the user may want the output rendered as text, not implemented as code.

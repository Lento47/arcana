# tui ambiguity in collaboration

TUI can mean either a coded terminal framework or a text-based visual rendered in chat — always clarify intent

**Why:** The user said "TUI" and "Gantt timeline dashboard in TUI" which were interpreted as a software framework (SolidJS/OpenTUI) requiring code exploration, route creation, and component building. It took two rounds of back-and-forth before the user clarified they meant a text visualization rendered directly in the chat interface, not a coded application.

**How to apply:** When a user asks for a "dashboard" or specific UI framework, ask clarifying questions early — offer concrete options (coded vs. text-rendered, web vs. terminal) before investing in exploration. For chat-based sessions, default to rendering visualizations as text/ASCII unless the user explicitly asks for code.

# Contracts

This directory contains example machine-readable Agent Contracts.

Contracts define bounded autonomous work:

```txt
goal
scope
allowed actions
forbidden actions
success criteria
verification
budget
risk escalation
```

## Examples

- `safe-refactor.contract.example.json`
- `dependency-change.contract.example.json`

## Status

These are examples for the Agent Operating Layer branch. Runtime contract validation/enforcement is not implemented in this branch.

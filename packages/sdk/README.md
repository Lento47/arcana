# @arcana/sdk

Typed client SDK for Arcana.

## Overview

Provides a TypeScript SDK for interacting with the Arcana runtime API.

## Features

- Type-safe API client
- Session management
- Approval workflows
- Proof verification

## Usage

```typescript
import { createClient } from "@arcana/sdk/v2"

const client = createClient({ url: "http://localhost:3000" })
```

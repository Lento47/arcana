# @arcana/script

Build, release, and automation scripts for Arcana.

## Overview

Contains build scripts, release tooling, and automation utilities.

## Scripts

- `build.ts` — Engine binary compilation
- `smoke.ts` — Smoke testing
- `patch-opentui.ts` — OpenTUI patches

## Usage

```bash
bun run build        # Build all packages
bun run smoke        # Run smoke tests
```

# @arcana/memory

SQLite + FTS5 memory system for Arcana agents.

## Overview

Provides persistent memory storage with full-text search capabilities for agent context and knowledge management.

## Features

- SQLite storage with FTS5 indexing
- Full-text search across memories
- Session-scoped memory isolation
- Automatic memory consolidation

## Usage

```typescript
import { MemoryStore } from "@arcana/memory/store"
```

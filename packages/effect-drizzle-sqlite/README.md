# @arcana/effect-drizzle-sqlite

Effect ↔ Drizzle ORM bridge for SQLite.

## Overview

Provides Effect-native wrappers for Drizzle ORM operations with SQLite.

## Features

- Effect-based query execution
- Transaction support
- Error handling via Effect

## Usage

```typescript
import { Database } from "@arcana/effect-drizzle-sqlite/database"
```

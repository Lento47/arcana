# @arcana/gateway

Messaging gateway adapters for Arcana — Telegram, Discord, Slack, WhatsApp.

## Overview

Provides adapters to connect Arcana agents with external messaging platforms.

## Supported Platforms

- Telegram
- Discord
- Slack
- WhatsApp

## Usage

```typescript
import { TelegramAdapter } from "@arcana/gateway/telegram"
import { DiscordAdapter } from "@arcana/gateway/discord"
```

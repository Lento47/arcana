Fetch content from URL. Takes URL + optional format. Returns content in requested format (markdown default).

- If better web-fetch tool available, prefer it.
- Use websearch first to find the right URL; fetch only the specific page you need
- One good fetch beats several speculative ones
- URL must be fully-formed valid URL
- HTTP auto-upgraded to HTTPS
- Format: "markdown" (default), "text", "html"
- Read-only, no file modification
- Large content is returned in full

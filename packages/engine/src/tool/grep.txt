Fast content search via ripgrep (Rust regex). Works with any codebase size.

Write ONE strong pattern instead of many weak calls:
- Alternatives in a single pass: "parseConfig|loadConfig|readConfig"
- Definitions or uses together: "(export\s+)?(async\s+)?function\s+parseConfig|parseConfig\s*\("
- Case-insensitive with word boundaries: "(?i)\b(config|settings)\b"
- Verbose multi-term pattern: "(?x)(foo|bar) \s* \("
- Escape literal punctuation: "foo\(", "a\.b"
- Scope the call: include "*.{ts,tsx}", path "src/"
- Rust regex has no lookahead, lookbehind, or backreferences - combine alternatives instead

Returns the whole matching line with file path and line number (each line up to 2000 chars), grouped by file. The matching line often answers without opening the file.
- Results are capped (default 500, see maxResults). When truncated, narrow include/path or raise maxResults instead of repeating the search.
- To count matches, use the bash tool with "rg -c". Do NOT pipe grep.
- For open-ended search with multiple rounds, delegate to the task tool.

Fast file pattern matching via ripgrep. Works with any codebase size.

- Combine alternatives with braces in one pattern: "**/*.{ts,tsx}", "src/**/*.{js,jsx}"
- One call can cover several speculative patterns - batch independent calls in the same turn
- Narrow with path: "src/components" searches only that subtree
- Returns absolute file paths in traversal order (not sorted)
- Use to find files by name; use grep for file contents
- For open-ended multi-round glob+grep, delegate to the task tool

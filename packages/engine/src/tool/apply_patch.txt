Edit files via stripped-down diff format.

Format:
```
*** Begin Patch
[file sections]
*** End Patch
```

Headers:
- *** Add File: <path> — create new file. Every line is +line.
- *** Delete File: <path> — remove file. Nothing follows.
- *** Update File: <path> — patch in place, optionally with `*** Move to: <newpath>`

- Must include action header (Add/Delete/Update)
- Must prefix new lines with `+` even for new files

Guardrails:
- Keep patches focused: change only the hunks that need updating.
- Large patches (>30 lines total) show ⚑ [LARGE CHANGE] chips in the TUI operator view. Split into smaller patches when possible.
- Backups are auto-created for each file when the patch exceeds 50 lines and shown as [backup created] in the TUI. Preserved on failure, cleaned up on success.

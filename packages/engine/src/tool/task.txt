Launch a subagent for parallel work. The subagent runs in its own context with its own tools.

When to use:
- Work on independent files that can proceed in parallel
- Research tasks that benefit from focused exploration
- The user asks to "use subagents", "delegate", or "run in parallel"

When NOT to use:
- Tasks under ~10 tool calls (do them inline)
- Sequential work where each step depends on the previous result
- Single-file changes

subagent_type: "general" for coding, "explore" for research, "qa" for bug-finding

Each subagent prompt must be self-contained: the goal, context, exact deliverable, and how to verify.
Synthesize results into one answer with per-subagent attribution.
